# Autonomous Trading

Autonomous **paper** trading is supported via `PaperTradingEngine` + RiskEngine.

```text
TRADING_MODE=paper
LIVE_TRADING_ENABLED=false
Live Execution=DISABLED
```

See `docs/PAPER_TRADING.md`, `docs/PAPER_TRADING_SAFETY.md`, and `docs/RISK_MANAGEMENT.md`.

Live / authenticated exchange execution is not implemented as an enabled path.
